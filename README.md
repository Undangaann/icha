# Undangan Digital Dark Gold Elegance

Undangan pernikahan digital berbasis HTML, CSS, dan JavaScript interaktif dengan nuansa adat elegan **Dark Gold & Traditional Motif** (referensi foto Bugis/Makassar/Jawa dengan ornamen mandala dan busana adat mewah).

## 🌟 Fitur Utama
1. **Cover Sampul Interaktif**: Tombol "Buka Undangan" untuk membukan konten utama disertai efek transisi pudar dan autoplay musik.
2. **Kustomisasi Nama Tamu via URL Query**:
   Format URL: `index.html?to=Nama+Tamu`
   Contoh: `index.html?to=Sri%20Mega%20Yunita%20K`
3. **Desain Responsive & Luxury**: Tema warna Hitam Arang, Emas Murni, dan aksen Ornamen Tradisional.
4. **Hitung Mundur Waktu (Countdown)**: Menggunakan JavaScript real-time menuju hari H.
5. **Form RSVP & Buku Tamu (Ucapan)**: Pengunjung dapat mengisi kehadiran dan ucapan secara langsung.
6. **Salin Rekening (Digital Gift)**: Tombol *one-click copy* nomor rekening BCA / Mandiri.
7. **Musik Latar**: Tombol putar/henti musik melayang (floating player).
8. **Siap Upload ke GitHub Pages**: Struktur folder bersih, terpisah (HTML, CSS, JS, Assets).

## 📁 Struktur Folder

undangan-digital-dark-gold/

## 🚀 Cara Live ke GitHub Pages
1. Buat Repository baru di GitHub (misal: `undangan-imma-wahyu`).
2. Upload semua berkas dari direktori ini ke repository tersebut.
3. Buka **Settings** > **Pages** pada repository GitHub Anda.
4. Pilih **Source** ke branch `main` (atau `master`) dan folder `/ (root)`.
5. Klik **Save**. Dalam beberapa detik website Anda akan live pada URL:
   `https://<username_github>.github.io/<nama_repo>/?to=Sri%20Mega%20Yunita%20K`
